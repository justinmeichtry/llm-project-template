# Local Reference Material

Files placed in this directory are intended for local use by humans and coding agents but are **not committed to Git by default**.

Suitable content:

- vendor manuals,
- API documentation exports,
- internal reference documents,
- example source files,
- large PDFs,
- local data dictionaries,
- non-secret screenshots or specifications.

Do **not** store:

- passwords,
- API keys,
- access tokens,
- private certificates,
- credentials,
- other secrets.

The `.gitignore` keeps this README while ignoring other files in this directory.
